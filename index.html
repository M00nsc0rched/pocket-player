Import a game packaged as a .zip (for RPG Maker MV: the contents of the game's www folder). Files are stored in this browser, on this device only — nothing is uploaded anywhere. You can keep several games side by side; each has its own saves.

iPhone — the order matters:
1. From THIS page: Share → Add to Home Screen (from the player page, not from inside a game).
2. Open the new home-screen icon — and do the import there.
3. Tap ▶ next to a game to play.

Safari and the installed app have separate storage on iOS — a game imported in Safari is invisible to the app, and vice versa. Each game keeps its own saves; removing the app removes every game and its saves.
